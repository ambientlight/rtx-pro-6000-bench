# Repository agent instructions

## Delegated work

- The main agent must allow subagents to complete delegated work at their natural pace.
- Do not send messages asking subagents to hurry, return early, stop investigating, or provide a premature summary merely because several minutes have elapsed.
- Do not interrupt an active subagent solely to obtain a status update. Use non-interrupting status inspection when available, then wait with a suitably long interval.
- Request an early return only when the user changes priorities, the result is no longer needed, a concrete deadline requires it, or there is evidence that the subagent is stuck or working out of scope.
- When no exceptional condition applies, preserve the original task scope and wait for the subagent's final result.
